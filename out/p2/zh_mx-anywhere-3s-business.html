MX 系列体验

基于数十年来人类互动的实用和科学专业知识，我们创造了 MX 系列来提供直观的体验。鼠标不仅令人爱不释手，还可提升表现和幸福感。

未来的建设者

MX 系列非常适合编码和创意工作等专业化工作流程，满足相应需求。MX 系列产品经久耐用，采用坚固的优质材料制成，旨在提升信心和办公专注度。

小巧便携

随时随地办公，尽享 MX Anywhere 3S 商用产品出众的多功能和性能。无论是在家中、办公室还是在旅途中，无论身处何处，均可舒适办公。

多设备、多操作系统兼容性

MX 产品均可在桌面电脑、笔记本电脑和平板电脑上搭配各种主流的企业操作系统和业务应用程序使用。这简化了大规模部署，并减少了 IT 服务台的工作量。

多电脑控制，多重连接

  • Easy-Switch™ 按键，支持多达 3 台电脑
  • 罗技 Flow 技术跨电脑和操作系统控制和文件共享需要 Logi Options+ 应用程序支持 Windows 和 macOS下载请访问 logitech.com/optionsplus
  • 最多可将六个罗技 Bolt 产品与一只罗技 Bolt 接收器配对需要 Logi Options+ 应用程序，支持 Windows 和 macOS，下载请访问 logitech.com/optionsplus

  • 搭载可充电锂离子电池（500 毫安），可边充电边使用（USB-C 充电端口）

  • Logi Bolt USB 接收器：Windows、macOS、LinuxWindows 和 macOS 之外的操作系统无需软件即可支持设备的基本功能，ChromeOS Windows 和 macOS 之外的操作系统无需软件即可支持设备的基本功能

Logi Bolt 无线技术

  • 在拥挤的无线环境中也能提供最远 10 米的覆盖范围无线接收范围因工作环境和电脑设置而异
  • 安全模式 1，安全级别 4 联邦信息处理标准 (FIPS) 模式

主要特性

快捷高效

采用回收塑料制造

优质的可持续发展材料可提升工作体验，同时支持环保目标。MX Anywhere 3S 商用中的塑料部件包含 78% 经认证的消费后回收塑料不包括印刷线路组件 (PWA)、接收器、线缆、FFC 线缆和包装中的塑料。。

即插即用，轻松方便

鼠标已与 Logi Bolt USB 接收器配对，设置简便。通过 Logi Bolt 连接实现高性能的安全连接，或通过 蓝牙™ 低功耗技术实现灵活的连接。

为大规模部署而打造

在全球超过 100 个国家/地区销售并获得认证，提供 2 年有限硬件保修。通过我们的 prosupport 支持平台为 IT 职业人士和商业用户提供支持。

持久电量

MX Anywhere 3S 商用鼠标完全充电后可使用长达 70 天，一分钟快速充电即可使用三小时。可以边充电边使用，无需中断办公。电池寿命依用户及计算条件而异

以 LOGI OPTIONS+ 实现非凡高效

Logi Options+ 应用程序让用户可以掌控自己的工作流程。使用 Flow 跨设备和操作系统办公，设置追踪速度，自定义各个按钮，以及使用预定义的应用程序特定自定义设置需要 Logi Options+ 应用程序支持 Windows 和 macOS下载请访问 logitech.com/optionsplus。

# 用八爪鱼采集天猫罗技旗舰店（防封策略版）

目标：采集 https://logitech.tmall.com 全店单品的 **品名、售价、销量、评论数、产品链接**，导出 Excel。

## 一、准备

1. 到官网 https://www.bazhuayu.com 下载并安装「八爪鱼采集器」，注册一个免费账号（免费版每天可导出 1 万条，足够用）。
2. 打开软件后先别急着建任务，看下面的防封设置原则。

## 二、防封号三原则（最重要）

1. **只用「本地采集」，不要用「云采集」**。云采集用的是八爪鱼服务器的 IP，和你登录天猫的 IP 不一致，风控立刻就能察觉，等于主动送人头。
2. **速度调慢**：任务设置里把「执行前等待」设为 3~5 秒并勾选随机等待；翻页和点击都加等待。宁可慢一小时，不要快十分钟。
3. **一天最多跑 1~2 轮**。如果采集中弹出滑块验证，在八爪鱼内置浏览器里手动划掉即可；如果反复弹滑块或要求重新登录，立即停止，隔天再采。

## 三、建任务（两条路，先试 A）

### 路线 A：模板采集（最简单）

1. 八爪鱼首页顶部搜索框搜「**天猫**」，看模板库里有没有「天猫店铺商品列表」类模板；
2. 有的话直接使用模板，参数里填店铺链接 `https://logitech.tmall.com/search.htm`；
3. 模板要求登录时，会在内置浏览器里弹出天猫登录页 → 手机淘宝扫码；
4. 启动**本地采集**。
   - 注意：模板一般只能采到列表页字段（品名/价格/销量/链接），**评论数往往采不到**，需要按路线 B 补详情页步骤，或者接受用"销量"代替。

### 路线 B：自定义采集（字段最全，推荐）

1. 「+新建」→「自定义任务」→ 网址填 `https://logitech.tmall.com/search.htm` → 保存；
2. 内置浏览器打开后**先扫码登录天猫**（登录态会保存在任务里）；
3. 等商品列表加载出来，用**智能识别**（软件会自动提示"已识别到列表"）→ 生成「循环列表」；
4. 字段整理：保留/添加这些字段——
   - **商品标题**（选中第一个商品标题 → 采集该元素的文本）
   - **价格**（点价格数字 → 采集文本）
   - **销量**（点"已售/总销量"文字 → 采集文本）
   - **商品链接**（点商品标题 → 采集该链接地址）
5. 翻页：点击页面底部「下一页」按钮 → 选「循环点击下一页」；
   - 天猫翻页是 Ajax 加载，给翻页步骤设置「执行前等待 3~5 秒」+「页面加载超时 10 秒」；
6. **采评论数（进详情页）**：在循环里对商品标题设置「点击元素」进入详情页 →
   在详情页点「累计评价」的数字 → 采集文本 → 设置「点击后返回」；
   - 详情页步骤同样加 3~5 秒等待；
7. 保存 → 启动「**本地采集**」→ 采集完成后「导出数据」→ 选 Excel。

## 四、任务设置里的具体参数（照抄）

| 设置项 | 值 |
|---|---|
| 采集方式 | 本地采集 |
| 执行前等待 | 3~5 秒，勾选「随机」 |
| 翻页/点击后等待 | 3~5 秒 |
| Ajax 超时 | 10 秒 |
| 并发/多任务 | 不开 |
| 定时采集 | 不开（手动跑，盯着点） |
| 防屏蔽-清除 Cookie | **不勾**（要保持登录态） |
| 自动识别验证码 | 不开，弹出滑块手动划 |

## 五、采完之后

1. 导出的 Excel 里会混着「套装/套餐/组合/礼盒」类套包商品；
2. **把导出的 Excel 直接发给助手（Claude）**，我来帮你：过滤套包、去重、把"2.5万+"这类销量转成数字、统一整理成最终表格。

## 常见问题

- **弹滑块**：在内置浏览器里手动拖动滑块完成验证，任务会自己继续。
- **反复要求重新登录**：当天停止，第二天再跑（风控冷却）。
- **模板/智能识别失败**：天猫改版频繁，用路线 B 手动点选字段最稳。
- **免费版限制**：本地采集不限量，导出每天 1 万行内免费，本任务几百行完全够。

# 天猫罗技官方旗舰店商品采集工具

采集 https://logitech.tmall.com 全店**单品**数据（自动过滤套装/套包），字段：

| 品名 | 售价(元) | 销量 | 评论数 | 产品链接 | 商品ID |
|------|---------|------|--------|----------|--------|

最终产出一个 Excel 文件（两个工作表：`单品` 和 `已过滤-套包`，后者供人工核对过滤是否准确）。

## 为什么必须在本地电脑运行

天猫查看店铺商品需要**扫码登录**，而且随时可能弹出**滑动验证**，这两步都必须真人操作，
无法在云端无人环境完成。本工具会打开一个真实浏览器窗口，你扫一次码即可，登录状态会保存。

## 使用步骤（Windows / macOS 均可）

1. 安装 Python 3.9+（https://www.python.org/downloads/ ，安装时勾选 "Add to PATH"）
2. 在本目录打开终端，执行：

   ```bash
   pip install -r requirements.txt
   playwright install chromium
   python scrape_tmall_store.py
   ```

3. 浏览器窗口弹出后，按终端提示**用手机淘宝扫码登录**，然后回终端按回车；
4. 之后全自动运行：先收集全店商品链接，再逐个进详情页取数据。
   罗技全店约几百个商品，按默认 4~9 秒/个的安全节奏，预计 30~60 分钟；
5. 结束后自动导出 Excel 到 `data/罗技官方旗舰店_商品数据_日期.xlsx`。

## 防封号设计（务必遵守）

- **单线程 + 随机间隔 4~9 秒**：等同一个人翻页浏览的速度，不要调低；
- **用真实浏览器 + 你自己的登录态**：没有并发请求、不伪造接口签名；
- **遇到滑块自动暂停**：手动划完滑块、按回车即可继续；若频繁出滑块，
  停止运行，隔几个小时再继续（有断点续采，进度不丢）；
- **断点续采**：随时 Ctrl+C 中断，再次运行会跳过已采集的商品；
- 连续失败 5 个商品会自动停止保护账号；
- 建议在非高峰时段（如上午）分 1~2 次采完，不要一天反复跑多轮。

## 常用命令

```bash
python scrape_tmall_store.py                     # 完整采集 + 导出
python scrape_tmall_store.py --export-only       # 只重新导出 Excel（不联网）
python scrape_tmall_store.py --min-delay 8 --max-delay 15   # 更保守的节奏
python scrape_tmall_store.py --exclude "套装,套餐,组合,礼盒" # 自定义套包过滤词
python scrape_tmall_store.py --no-details        # 只收集商品链接
```

## 产出文件

- `data/item_urls.json` — 全店商品链接清单
- `data/items.jsonl` — 逐条采集的原始数据（断点续采依赖它）
- `data/罗技官方旗舰店_商品数据_YYYYMMDD.xlsx` — 最终表格

## 关于价格（重要）

天猫对**价格**用了"字体加密"：网页上肉眼看到的价格是对的，但采集器抓到的是乱码
（其它工具如后羿、八爪鱼同样如此）。本工具的破解办法是**把价格截图后用 OCR 识别成数字**
（读屏幕上画出来的像素，绕过加密）。这依赖 `ddddocr` 组件，一键运行脚本会自动尝试安装；
若你的 Python 版本太新导致该组件装不上，程序仍会正常采集其它字段，只是价格列为空——
这种情况把 Excel 发给助手，或改用 Python 3.12 重装即可。

## 注意

- 天猫页面结构会不定期改版。如果运行时提示"未提取到标题"或找不到商品链接，
  把终端输出和浏览器里看到的页面截图发回来，我来更新选择器。
- 销量显示为"2.5万+"时按下限 25000 记录。
- 评论数来自商品详情页的"累计评价"。
